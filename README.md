## 🏫 Little Learners

A modern, multi-page educational platform built with **React**. It provides a comprehensive overview of the institution's offerings and values.

### ✨ Key Features

- 📝 **Multi-page structure** (Home, About, Rooms, Subjects, Contact, etc.)
- 🏆 **Awards showcase** with a 3-card slider
- 👨‍🏫 **Staff directory** with profiles
- 📚 **Subjects & curriculum** display
- 🖼️ **Rooms gallery** with images
- ⭐ **Testimonials slider** showcasing parent feedback
- ❓ **FAQ section** for common questions
- 📬 **Contact Us page** for inquiries
